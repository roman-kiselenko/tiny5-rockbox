# H2 Rockbox v0.0.3 — eight palettes, a flatter interface

Rockbox for the **HiFi Walker H2** (AIGO Eros Q native, Ingenic X1000, 320×240,
32 MB). The layout is the same as [v0.0.2](v0.0.2.md); what changed is how it is
drawn.

**Archive:** `rockbox-h2-v0.0.3.zip` (~2.65 MB) — unzip to the root of the SD
card (it contains `.rockbox/`). `unzip -o` over an existing install keeps
`config.cfg`, `bt_config.conf` and `bt_devices.txt`, so pairings and settings
survive.

## Eight palettes, one layout

**Dark**, **Light**, **Nord**, **Gotham**, **Rose Pine**, **Tokyo Night**,
**One Light** and **GitHub Light**. Same screens, same row heights, same
selection mechanics — only the colours change. Set the theme under
Settings › General › Display (`theme: nord` in `config.cfg`).

- **The accent is part of the palette.** The "accent colour" picker is gone:
  every theme carries its own accent, its lighter accent for fills, icons and
  plots, and its own warning red. A leftover `accent colour:` line in an old
  `config.cfg` is simply ignored.
- Each palette states its own secondary text colour, so the Minimal selection
  band no longer has a hard-coded grey.
- Palettes live in one table, `apps/newui/ui_style.c`. Adding one is a row in
  four tables plus a language phrase; no screen code is touched.

## Times read like a display

A second face is in the UI, for numerals only: **Digital-7**, a 9 px
seven-segment font (`fonts/newui/09-Digital7.fnt`, 208 bytes). `ui_text_num()`
draws runs of `0-9`, `:` and `-` with it and everything else with Tiny5, so the
status bar clock, the battery number, Now Playing's elapsed and remaining times,
Cover Flow's track lengths and the lock-screen clock look like a display while
`%`, letters and units stay Tiny5. Both faces are 9 px on the same baseline, so
mixed strings need no special alignment.

The `.bdf` is rasterised from the TTF by `tools/ttf2bdf.py`, a dependency-free
stdlib reader (glyf/loca/cmap, quadratic outlines, scanline fill at 4× the
target size so thin features survive); `tools/convbdf` then produces the `.fnt`.
No FreeType, no build step — the font is committed. Its licence is recorded in
`fonts/newui/LICENSE-Digital7.txt`: the TTF's own name table says "© 2008
Style-7, all rights reserved, freeware for personal use", which is thinner than
the OFL Tiny5 uses. Only `0123456789:-` are rasterised, and the `.bdf` is the
source of truth, so swapping in any other 9 px seven-segment face is a two-command
change with no code touched.

## Terminal-flat: the rules are gone

- The status bar is no longer a gradient band — it is the page's own colour,
  with only the play-state glyphs, clock, Bluetooth and battery drawn on it.
- Hairlines under list title rows and art rows, the top rule of the Now Playing
  info and volume bands, the line under the System Status title and the outlines
  of the Cover Flow song panel are removed. Bands are separated by colour only.
- Selection bands span the whole row height instead of `row_h - 1`.
- `UI_C_BAR_LINE` now means "the track a bar fills", not a separator.

Kept deliberately: the battery chart's dashed grid, and the cover frames in
Cover Flow, which are the edges of the covers, not decoration.

## Documentation split up

The README is now an introduction, a feature list, screenshots and references.
The detail lives in:

| File | Contents |
|---|---|
| `docs/INTERFACE.md` | screens, controls, fonts, languages, selection styles |
| `docs/BLUETOOTH.md` | the Bluedroid port, the BCM4343A1 driver, the settings |
| `docs/CUT-DOWN.md` | everything removed from upstream Rockbox |
| `docs/DEVELOPING.md` | builds, the simulator, the commit gate, releases |

`docs/screens/` has one folder per theme, produced by `ci/screens.sh` running
`ci/screens.script` in the headless simulator and `ci/scale2x.py` doubling the
320×240 shots to 640×480.

## Size

The firmware text is 1,540,972 bytes: the palette tables added ~130 bytes, the
removed status-bar gradient loop took 380, `ui_text_num()` added ~1100. The
archive is the firmware, the codecs, Tiny5 Mono (452 KB) and Digital-7 (208 B).

## Unchanged

- Bluetooth audio (A2DP + AVRCP) on **hw4** only.
- No plugins, no themes, no WPS files; codecs this player will not use stay out.
- CJK text is still deferred — Tiny5 Mono and the Digital-7 numerals are the
  only fonts installed, and `fonts/newui/mkfonts.sh` remains as the seed for a
  CJK build.
- New UI strings are English only; other languages fall back.

## Install

1. The player needs the **official Rockbox bootloader** for the Eros Q native.
   This tree does not build bootloaders.
2. Unzip to the card root, then eject and reboot.
3. An older install still carries the Noto Sans CJK faces (~27 MB) that are no
   longer used — delete `.rockbox/fonts/newui-*.fnt` to reclaim the space.

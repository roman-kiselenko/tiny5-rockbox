# Rockbox v0.0.3 — eight palettes, a flatter interface

Follows [v0.0.2](v0.0.2.md). The layout is unchanged; what changed is how it is
drawn.

## Eight palettes, one layout

**Dark**, **Light**, **Nord**, **Gotham**, **Rose Pine**, **Tokyo Night**,
**One Light** and **GitHub Light**: same screens, same row heights, same
selection mechanics, only the colours differ. Set it under
Settings › General › Display, or `theme: nord` in `config.cfg`.

- The accent is part of the palette — the "accent colour" setting is gone. Each
  theme carries its own accent, its lighter accent for fills, icons and plots,
  and its own warning red. A leftover `accent colour:` line in an old
  `config.cfg` is ignored.
- Each palette states its own secondary text colour, so the Minimal selection
  band no longer has a hard-coded grey.
- Palettes live in one table, `apps/newui/ui_style.c`. Adding one is a row in
  four tables plus a language phrase; no screen code is touched.

## Times read like a display

A second face is in the UI, for numerals only: **Digital-7**, a 9 px
seven-segment font (`fonts/newui/09-Digital7.fnt`, 208 bytes). `ui_text_num()`
draws runs of `0-9`, `:` and `-` with it and everything else with Tiny5, so the
status bar clock, the battery number, Now Playing's elapsed and remaining times,
Cover Flow's track lengths and the lock-screen clock look like a display, while
`%`, letters and units stay Tiny5. Both faces are 9 px on the same baseline, so
mixed strings need no special alignment.

The `.bdf` is rasterised from the TTF by `tools/ttf2bdf.py`, a dependency-free
stdlib reader, and `tools/convbdf` turns it into the `.fnt`: no FreeType, no
build step, the font is committed. Its licence is recorded in
`fonts/newui/LICENSE-Digital7.txt`; only `0123456789:-` are rasterised, and the
`.bdf` is the source of truth, so any other 9 px seven-segment face is a
two-command swap with no code touched.

## Terminal-flat: the rules are gone

- The status bar is no longer a gradient band — it is the page's own colour, with
  only the play-state glyphs, clock, Bluetooth and battery drawn on it.
- Hairlines under list title rows and art rows, the top rule of the Now Playing
  info and volume bands, the line under the System Status title and the outlines
  of the Cover Flow song panel are removed. Bands are separated by colour only.
- Selection bands span the whole row height instead of `row_h - 1`.
- `UI_C_BAR_LINE` now means "the track a bar fills", not a separator.

Kept deliberately: the battery chart's dashed grid, and the cover frames in
Cover Flow, which are the edges of the covers, not decoration.

## The logo is drawn, not shipped

Both marks of the Rockbox logo are vector geometry in the binary, cut from the
SVGs in `docs/logo` by `tools/svg2poly.py` (stdlib only, like `ttf2bdf.py`):
paths are flattened to polygons, normalised into a 1024 box and committed as
headers.

- **The boot splash is the Rockbox icon** — `logo_geometry.h`, 9 painted paths,
  17 rings, 570 points, each path with its own fill. `ui_logo_draw()` paints it
  even-odd at 120 px, half the screen height, in the bottom-left corner, and
  boot fades it in, opacity 0 to 1 easing over 2 s. The 230 KB `rockboxlogo.bmp`
  is gone.
- **An album with no cover carries the clef** — `clef_geometry.h`, 200 points in
  four rings — in every placeholder square: list rows, Cover Flow, and Now
  Playing, which keeps the cover square rather than letting the text float.
- Both are anti-aliased by sampling each pixel row on four sub-scanlines; the
  clef's coverage is cached per size, so a list of rows without art redraws
  cheaply while the wheel spins.
- Covers in a list's *title* row line up with the text below them: the edge
  column when the rows beneath have covers (the album page), the text margin
  when they do not (the context menu).

## Home knows the collection

Stuck to the bottom edge of Home, in the theme's secondary grey, is the music
database: `1246 tracks · 41 h 12 min`, the numbers in the seven-segment face.
The total is `tag_length` summed over every entry, scanned once and cached,
keyed on the entry count, how far a scan has got and the commit step; Home
refreshes the line when the database finishes building, so it does not have to be
left and re-entered. While the database is not searchable the line says so —
`Music database not ready yet [3/12]` — and when it holds nothing,
`No music in the database`.

## Pop-up panels are flat

The bar a scan shows during a disk or database scan is a flat 6 px band rather
than a pill, and the yes/no rows use the same flat selection band as every list.

## The splash shows both versions

The boot splash now has two version rows: `Rockbox: <build revision>` and, in
grey below it, `Tiny5 UI: vX.Y.Z` — the repository tag. `tools/version.sh
--release` resolves the tag (HEAD's tag on a release build, otherwise the release
the notes table says is next) and `tools/genversion.sh` writes it to `rbversion.h`
as `RBRELEASE`. The release workflow no longer sets `VERSION`, so the Rockbox line
stays the revision the firmware was built from.

## Documentation split up

The README is an introduction, a feature list, screenshots and references. The
detail lives in:

| File | Contents |
|---|---|
| `docs/INTERFACE.md` | screens, controls, fonts, languages, selection styles |
| `docs/BLUETOOTH.md` | the Bluedroid port, the BCM4343A1 driver, the settings |
| `docs/CUT-DOWN.md` | everything removed from upstream Rockbox |
| `docs/DEVELOPING.md` | builds, the simulator, the commit gate, releases |

`docs/screens/` has two folders, **dark** and **light**: `ci/screens.sh` runs
`ci/screens.script` in the headless simulator and `ci/scaleimg.py` upscales the
320×240 shots 4× to 1280×960, so the 9 px font is legible. `THEMES="nord gotham"
ci/screens.sh` shoots others.

## Install

1. **Archive:** `rockbox-v0.0.3.zip` (2.64 MB) — the firmware, the codecs, Tiny5
   Mono and the Digital-7 numerals.
2. The player needs the **official Rockbox bootloader** for the Eros Q native.
   This tree does not build bootloaders.
3. Unzip to the card root: `unzip -o rockbox-v0.0.3.zip -d /path/to/sdcard`.
   Over an existing install it leaves `config.cfg`, `bt_config.conf` and
   `bt_devices.txt` alone, so settings and Bluetooth pairings survive. Bluetooth
   audio needs hardware revision 4 (hw4).
4. Eject the card and reboot.
5. An older install still carries the Noto Sans CJK faces (~27 MB) that are no
   longer used — delete `.rockbox/fonts/newui-*.fnt` to reclaim the space.

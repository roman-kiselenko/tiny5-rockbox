# v1.1 — the last release of the original H2 port

Tagged 27 October 2026, before this repository started its own versioning.
These tags are inherited from [dismal-ad/h2-rockbox](https://github.com/dismal-ad/h2-rockbox),
the port this tree was forked from; the Tiny5 Mono interface releases start at
[v0.0.1](v0.0.1.md).

The interface at this tag:

- **Noto Sans CJK** as the UI font, so Chinese, Japanese and Korean rendered.
- iPod-style drawing: glass battery icon, album art rows, the fast-scroll letter
  box, two-line rows in the Songs list.
- Bluetooth on the Home screen rather than in Settings; headphone play/pause,
  next and previous.
- Battery turns red below 20%.
- One Power press wakes the screen after the backlight timeout.

There is no System Status screen and no Battery Usage chart yet, and the build
carries the 27 MB CJK fonts. `docs/screens/` has no shots of these screens —
they predate the screenshot scripts.

**Archive:** `rockbox-h2-v1.1.zip` if built from this tag. The firmware is still
runnable today, but it is twelve commits behind `master` and the settings it
writes are not all understood by the current build.

# Rockbox v0.0.4 — a font you can choose

Follows [v0.0.3](v0.0.3.md). The screens and layout are unchanged; what changed
is the type you read, the number the battery shows, and a little more air on the
Now Playing screen.

## A font you can choose

Two faces now ship, and you pick between them under **Settings › General ›
Display › Font**:

- **Tiny5 Mono** (the default) — the 9 px pixel font the whole UI has always
  drawn with.
- **Kode Mono Regular** — a taller, more even monospaced face, for anyone who
  finds Tiny5 a little cramped.

Selecting a face re-pins every screen to it at once, not just the ones that were
built to ask for it: the lists, the menus, the database browser, Now Playing,
Home and the status bar all follow. The two faces are different sizes, so each
carries its own five sizes internally; switching does not rescale the text.

- Tiny5 Mono stays the default on purpose: it is the one face that carries the
  small transport and status glyphs (play, pause, stop, the lock and Bluetooth
  marks). Kode Mono has no glyphs for those, so while it is selected the status
  bar still draws its icons — the two lines resolve to whatever is loaded.
- Both faces are installed by the build onto the card (`fonts/newui`), and their
  glyphs load on demand, so the extra face costs disk space, not RAM. An old
  selection in `config.cfg` still maps cleanly; the list has two entries.

## The battery number is steady now

The H2's power-management chip reports a fuel-gauge percentage directly. Reading
it had one weakness: if the momentary transfer to the chip failed — a common I2C
glitch or the chip busy with something else — the read returned an uninitialised
byte in 0–255 as the percentage, so the readout and the Battery Usage chart would
jump to a random number between polls.

It now retries the transfer a couple of times, and only if every attempt fails
does it fall back to the filtered voltage-based estimate that was always there —
never a stray value. The number changes only when the charge actually does.

## A little more room on Now Playing

The song-info readout on the Now Playing screen was packed at one exact line
height, so the title, artist, album, track number and file sat almost edge to
edge. Each line now has a little air beneath it, so the block reads as separate
lines; the cover above shrinks by the same amount to make room, and still shows.

## Install

1. **Archive:** `rockbox-v0.0.4.zip` (2.6 MB) — the firmware, the codecs and the
   two UI fonts, Tiny5 Mono and Kode Mono Regular.
2. The player needs the **official Rockbox bootloader** for the Eros Q native.
   This tree does not build bootloaders.
3. Unzip to the card root: `unzip -o rockbox-v0.0.4.zip -d /path/to/sdcard`.
   Over an existing install it leaves `config.cfg`, `bt_config.conf` and
   `bt_devices.txt` alone, so settings and Bluetooth pairings survive. Bluetooth
   audio needs hardware revision 4 (hw4).
4. Eject the card and reboot.

# v1.0 — the first packaged build of the H2 port

Tagged 24 October 2026 by [dismal-ad](https://github.com/dismal-ad) for the
original H2 port, before this repository forked it. The tag exists here so the
Release workflow can rebuild it if needed; the versioning of the Tiny5 Mono
interface starts at [v0.0.1](v0.0.1.md).

At this tag the player had: the code-drawn interface, Cover Flow, album art, the
file and database browsers, Bluetooth audio on hw4, and the Noto Sans CJK UI
fonts. No System Status, no Battery Usage chart, no Tiny5 Mono.

**Archive:** `rockbox-h2-v1.0.zip` — unzip to the SD card root.
